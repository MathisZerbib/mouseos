ひとことで

MouseOSとは。

MouseOSは、Androidスマホを、Mac、Windows PC、Linuxパソコンのためのワイヤレスなトラックパッド、エアマウス、キーボード、メディアリモコン、プレゼン用リモコンに変える無料アプリです。さらに、Samsung、LG、Google TVのテレビのリモコンにもなります。

スマホとパソコンは、お使いのWi‑Fiを通じて直接やりとりします。インターネットもアカウントもクラウドも不要、広告もトラッキングもありません。パソコン側には小さな無料アプリを入れるだけ。テレビには何も要りません。新しいスマホは、パソコンでALLOWを一度クリックすれば承認されます。

インストール

2分。一度だけ。

パソコンで始めて、スマホで終わり。両方を同じWi‑Fiにつないでおいてください。

  1. Macで

    ダウンロードして開く

    MouseOSをアプリケーションにドラッグして開きます。初回にmacOSに止められたら：システム設定 → プライバシーとセキュリティ → このまま開く。

    Mac用をダウンロード Apple silicon · macOS 11以降

  2. Macで

    操作を許可する

    ALLOW CONTROLをクリックし、MouseOSをオンにします。macOSは、アプリがポインタを動かす前に一度だけ確認します。

  3. スマホで

    スマホのアプリを開く

    AndroidスマホにMouseOSをインストールし、同じWi‑Fiで開きます。Macは自動で見つかります。

    ベータに参加 Android 8以降

  4. 再びMacで

    ALLOWをクリック

    新しいスマホごとに、Macが一度だけ確認します。これで完了 — スマホがマウスです。

スマホアプリを、誰よりも先に。

MouseOS for Androidは、Google Playでクローズドテスト中です。Googleアカウントのメールアドレスを残してください。テストに追加すると、MouseOSは他のアプリと同じようにGoogle Playからインストールでき、アップデートも届きます。

メールアドレスだけ、それ以外は何も要りません。テストへの追加と、公開のお知らせにのみ使います。ベータ終了時に削除します — それより早く削除したい場合は support@mouseos.app までひとこと。

問題が発生しました。 もう一度お試しいただくか、support@mouseos.app までメールをください。

よくある質問

無料ですか？

はい — スマホアプリもパソコンアプリも無料です。広告もありません。感謝の気持ちを伝えたい方のために、設定に任意のチップがあります。

どのパソコンで使えますか？

Apple silicon（M1以降）搭載のMac、macOS 11以降。Windows 10および11、64ビット。Linux、64ビット — Ubuntu、Debian、Fedoraなど、X11またはWayland。

Androidアプリはどうやって入手しますか？

Google Playでクローズドテスト中です。Googleアカウントのメールアドレスでベータに参加してください。テストに追加すると、MouseOSは他のアプリと同じようにGoogle Playからインストールでき、アップデートも届きます。

iPhoneは？

まずはAndroidから。iPhone版は準備中です。

どのテレビで使えますか？

Samsung、LG、Google TV（Sony、TCL、Philipsなど）。

インターネットは必要ですか？

いいえ。スマホとパソコンはWi‑Fiを通じて直接やりとりします — サーバーは一切経由しません。インターネットもアカウントも不要です。スマホのテザリングでも使えます。

BluetoothですかWi‑Fiですか？

Wi‑Fiです。Bluetoothではありません。MouseOSはローカルネットワーク上のパソコンを自動で見つけます。パソコンでALLOWを一度クリックすれば、ペアリングは完了です。

テレビにパソコン用アプリは必要ですか？

いいえ。テレビ画面は、同じWi‑Fi上のSamsung、LG、Google TVと直接やりとりします。

プレゼンに使えますか？

はい。スライド画面には巨大な「次へ」と「前へ」、分単位で設定できるタイマーがあり、スマホの音量ボタンでもめくれます。

文字入力や音量操作はできますか？

はい。キーボード画面はどんな言語でも入力でき、アクセント記号も絵文字も使えます。リモコン画面には矢印キー、再生、パソコンの音量、次のエピソードがあります。

他の人に自分のパソコンを操作されませんか？

されません。新しいスマホは、パソコン側でALLOWをクリックしない限り接続できません。

うまくいかない？

macOSで開けない

システム設定 → プライバシーとセキュリティで下にスクロールし、このまま開くをクリックします。初回のみです。

WindowsがPCを保護したと表示する

詳細情報、次に実行をクリックします。初回のみです。MouseOSはまだMicrosoftの署名を受けていません。

スマホがパソコンを見つけられない

同じWi‑Fiに接続し、VPNをオフにしてください。カフェやホテルのWi‑Fiは機器同士を隠すことがあります。スマホのテザリングをオンにして、パソコンからそこに接続してください。Windowsでは、Wi‑Fiがプライベートネットワークである必要があります。または、スマホでTYPE THE ADDRESSをタップしてください。

ポインタが動かない

Mac：システム設定 → プライバシーとセキュリティ → アクセシビリティで、MouseOSをオンにします。Linux（Wayland）：MouseOSを開いてALLOW CONTROLをクリックします。アップデート後は、アプリが手順を案内します。
