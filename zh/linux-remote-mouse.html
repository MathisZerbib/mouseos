手机当 Linux 的鼠标 — 包括 Wayland

大多数手机鼠标应用止步于 X11。MouseOS 还能控制 Wayland 上的 GNOME 和 KDE Plasma：触控板、空中鼠标、键盘和媒体键，从安卓手机，通过你的网络。

安装

  1. 下载 .deb（Ubuntu、Debian、Mint）或 .rpm（Fedora、openSUSE），用你的包管理器安装。
  2. 打开 MouseOS。在 Wayland 上，点击 ALLOW CONTROL 并输入一次密码（详见下文）。在 X11 上不需要任何授权。
  3. 在同一个网络下打开手机上的 MouseOS。在电脑上为这台手机点击 ALLOW。完成。

在各种会话下的工作原理

会话输入如何送达
X11XTest — 指针、按键、两个滚动轴、任意键盘布局下的 Unicode 输入。
Wayland通过 uinput 创建虚拟鼠标和键盘，合成器把它们当作真实硬件。ALLOW CONTROL 会执行一步 pkexec，添加一条 udev 规则，给 /dev/uinput 打上 uaccess 标签 — 仅允许已登录用户访问 — 并在开机时加载模块。

想手动操作？应用会显示它将运行的三条命令。音量通过 PipeWire 或 PulseAudio 控制；媒体键会送达前台的播放器。

网络

  • 点击、按键和状态：TCP 53317 上的 WebSocket。指针和滚动：UDP 53318，只接受你允许过的手机。
  • 发现：mDNS 加 UDP 信标 — 不用输入 IP。如果防火墙拦截，就为局域网开放这两个端口，或者输入应用显示的地址。
  • 没有服务器，无需账号，没有遥测。任何数据都不会离开你的网络。
