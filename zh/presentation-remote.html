手机就是演示翻页器

翻页器在另一个包里。电池没电了。USB 接收器插不上。你有手机 — 这就够了。

幻灯片界面能做什么

  • 超大的 NEXT 和 PREV — 不用低头也能按准。
  • 音量键翻页（安卓）：手机放在口袋里，拇指搭在侧边。
  • START 能识别前台应用：在 Mac 上，它会用正确的快捷键在 Keynote、PowerPoint、Google 幻灯片或预览中启动放映。
  • BLACK 在你想让全场看着你时把屏幕变黑；END 退出放映。
  • 精确到分钟的演讲计时器。在剩余 5 分钟、1 分钟和时间到时震动提醒 — 不用看表。
  • 需要指点什么？切换到 Air，把手机指向屏幕。

演讲前设置好

  1. 在笔记本上安装免费的 MouseOS 应用 — Mac、Windows 或 Linux — 并允许一次控制。
  2. 在同一个 Wi‑Fi 下打开手机上的 MouseOS。在笔记本上点击 ALLOW。手机会记住它。
  3. 打开演示文稿，点击 START。

会场 Wi‑Fi？

会场和酒店的网络常常让设备之间互相看不见。这个办法在哪里都管用：打开手机热点，让笔记本连接热点。MouseOS 不需要互联网 — 手机和笔记本直接通信。

支持

任何用方向键翻页的软件：Keynote、PowerPoint、Google 幻灯片、LibreOffice Impress、PDF 阅读器、reveal.js 和其他网页演示 — 在 Mac、Windows PC 或 Linux 笔记本上。
