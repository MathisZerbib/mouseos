简而言之

MouseOS 是什么。

MouseOS 是一款免费应用，把你的安卓手机变成 Mac、Windows PC 或 Linux 电脑的无线触控板、空中鼠标、键盘、媒体遥控器和演示翻页器 — 也能变成三星、LG 或 Google TV 电视的遥控器。

手机和电脑通过你的 Wi‑Fi 直接通信。不需要互联网，无需账号，不走云端，没有广告，没有追踪。电脑上运行一个小小的免费配套应用；电视则什么都不需要。每台新手机只需在电脑上点一次 ALLOW 即可获准。

两分钟。只需一次。

从电脑开始，在手机上完成。两台设备连接同一个 Wi‑Fi。

  1. 在 Mac 上

    下载并打开

    把 MouseOS 拖入应用程序并打开。如果第一次被 macOS 拦下：系统设置 → 隐私与安全性 → 仍要打开。

    下载 Mac 版 Apple 芯片 · macOS 11+

  2. 在 Mac 上

    允许控制

    点击 ALLOW CONTROL，然后打开 MouseOS 的开关。任何应用要移动指针，macOS 都会先询问一次。

  3. 在手机上

    打开手机应用

    在安卓手机上安装 MouseOS，在同一个 Wi‑Fi 下打开。它会自动找到你的 Mac。

    点击 ALLOW

常见问题

免费吗？

是的 — 手机应用和电脑应用都免费。没有广告。如果你想表达谢意，设置里有可自愿的打赏。

支持哪些电脑？

搭载 Apple 芯片（M1 及更新）的 Mac，macOS 11 或更高版本。Windows 10 和 11，64 位。Linux，64 位 — Ubuntu、Debian、Fedora 等，X11 或 Wayland。

怎样获得安卓应用？

它正在 Google Play 进行封闭测试。用你的 Google 账号邮箱加入测试版：我们把你加入测试，然后 MouseOS 就能像其他应用一样从 Google Play 安装，更新也会自动送达。

iPhone 呢？

安卓优先。iPhone 版即将推出。

支持哪些电视？

三星、LG 和 Google TV（索尼、TCL、飞利浦……）。

需要互联网吗？

不需要。手机和电脑通过你的 Wi‑Fi 直接通信 — 不经过任何服务器。不需要互联网，无需账号。手机热点也可以。

蓝牙还是 Wi‑Fi？

Wi‑Fi，不是蓝牙。MouseOS 会在局域网里自动找到你的电脑；在电脑上点一次 ALLOW，配对就完成了。

电视需要电脑端应用吗？

不需要。电视界面通过同一个 Wi‑Fi 直接与你的三星、LG 或 Google TV 电视通信。

可以用来做演示吗？

可以。幻灯片界面有超大的“下一页”和“上一页”、精确到分钟的计时器，手机的音量键也能翻页。

可以打字和控制音量吗？

可以。键盘界面支持任何语言输入，包括重音符号和表情符号。遥控器界面有方向键、播放、电脑音量和下一集。

别人能控制我的电脑吗？

不能。每台新手机都需要在电脑上点一次 ALLOW。

遇到问题？

macOS 不让打开

系统设置 → 隐私与安全性，向下滚动，点击仍要打开。仅第一次需要。

Windows 提示已保护你的电脑

点击更多信息，再点击仍要运行。仅第一次需要：MouseOS 尚未经过微软签名。

手机找不到电脑

确保在同一个 Wi‑Fi 下，并关闭 VPN。咖啡馆或酒店的 Wi‑Fi 会隐藏设备：打开手机热点，让电脑连接热点。在 Windows 上，Wi‑Fi 必须设为专用网络。或者在手机上点击 TYPE THE ADDRESS。

指针不动

Mac：系统设置 → 隐私与安全性 → 辅助功能：打开 MouseOS 的开关。Wayland 上的 Linux：打开 MouseOS 并点击 ALLOW CONTROL。更新后，应用会告诉你怎么做。
